# Obstetric Terminology Glossary

## Genel Bakış
Bu sözlük, kullanıcının girdiği Türkçe semptomların, sistemdeki İngilizce veya tıbbi karşılıklarıyla doğru eşleştirilebilmesi (retrieval optimizasyonu) için kurgulanmıştır.

## Terminology Mapping (Terim Eşleştirmeleri)
* baş ağrısı → headache
* kanama → bleeding
* lekelenme → spotting
* kasılma → contraction
* su gelmesi → amniotic fluid leakage
* bebek hareketi → fetal movement
* nefes darlığı → shortness of breath
* bulantı → nausea
* kusma → vomiting
* ateş → fever
* karın ağrısı → abdominal pain
* ödem (şişlik) → edema
* yüksek tansiyon → hypertension
* erken doğum → preterm labor
* bulanık görme → blurred vision
* ışık çakması → flashing lights
* şişlik → swelling
* el şişmesi → hand swelling
* yüz şişmesi → facial swelling
* çarpıntı → palpitations
* baş dönmesi → dizziness
